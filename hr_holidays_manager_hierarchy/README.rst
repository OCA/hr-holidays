By default, only the direct time off approver of an employee (the *Time
Off* field on the employee) can see and approve their time off requests.
Managers higher up in the hierarchy have no access to them.

This module extends that access in cascade through the employee
hierarchy (*Manager* field): a time off responsible can see, approve and
refuse the time off requests of every employee below them, at any depth.

Managers in the hierarchy get exactly the same rights as the direct
approver:

- Time off types validated by the Time Off Officer still require an
  officer.
- Nobody can approve their own requests.

The *Approve* and *Refuse* buttons of the time off list and kanban views
are only shown when the user can actually approve the request, as the
form view already does, and the *Validate* button (second approval) is
only shown to Time Off Officers, the only ones allowed to use it.

Configuration
=============

The cascade applies to users in the *Time Off / Responsible* group. Odoo
adds users to this group automatically when they are set as time off
approver of an employee, and removes them when they stop being one, so
in most cases no configuration is needed.

Users who manage employees in the hierarchy but are not the time off
approver of anybody must be added to the group manually.

Usage
=====

1. Go to *Time Off > Management > Time Off*.
2. Use the *My Team (Hierarchy)* filter to list the time off of all the
   employees below you in the hierarchy.
3. Approve or refuse the requests as their direct approver would.

Known issues / Roadmap
======================

- Managers higher up in the hierarchy cannot modify or refuse a time off
  that has already begun and is no longer pending of the first approval,
  while the direct time off approver can. Odoo performs this check
  inline in ``hr.leave.write()``, comparing with the employee's time off
  manager, so it cannot be extended without bypassing the standard write
  checks.
