This module lets you define reusable public holiday schedules and
generate them into native work-calendar leaves.

A schedule lists the countries it applies to and a set of rules: fixed
dates, dates relative to Easter, nth weekday of a month, and custom
rules. Rules can be limited by country, state, or postal code range.
Generation writes ``resource.calendar.leaves`` for each applicable
company, so core Time Off counts those days without any extra holiday
catalog.

Configuration
=============

Go to *Time Off > Configuration > Holiday Schedules* and create a
schedule.

- Set the countries the schedule applies to.
- Set *Year to Generate*.
- Add rules for fixed dates, Easter-relative dates, or nth weekday of a
  month. Add an observed-date shift when a holiday should move off the
  weekend.
- Optionally limit a rule by country, state, or zip range.
- Archive a rule (*Active* unchecked) to skip it in a given year, for
  example a discretionary holiday such as Carnival.

Usage
=====

Open a schedule and review the *Preview* tab, then click *Generate*.

Country-wide rules create one company-wide calendar closure per
applicable company. Rules limited by state or zip create
resource-specific closures for matching employees. Running *Generate*
again for the same year does not duplicate leaves. *Delete Generated*
removes the leaves created for *Year to Generate*.
