Go to *Time Off > Configuration > Holiday Schedules* and create a schedule.

- Set the countries the schedule applies to.
- Set *Year to Generate*.
- Add rules for fixed dates, Easter-relative dates, or nth weekday of a
  month. Add an observed-date shift when a holiday should move off the
  weekend.
- Optionally limit a rule by country, state, or zip range.
- Archive a rule (*Active* unchecked) to skip it in a given year, for example
  a discretionary holiday such as Carnival.
